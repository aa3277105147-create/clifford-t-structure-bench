# Clifford+T 电路的指定振幅计算

调试量子电路时，有时只关心一个结果。给定输入比特串 `x` 和目标输出 `y`，计算从 `x` 到 `y` 的复振幅，就能比较两种实现对这个输出的预测。这个项目用同一批电路实测三种节省计算时间的办法。

## 1. 只算一个振幅，先整理电路划算吗？

把原电路直接交给 Quimb，与先做一组固定的预处理、再交给同一个模拟器相比。计时从读入任务开始，包含预处理、规划和求值。

**固定预处理的中位加速比为 3.29 倍。** 在 230 条可核验的配对任务中，202 条更快，28 条更慢。可逆算术电路受益最多，中位加速比为 9.82 倍。IQP 电路则整体变慢。另一种做法是为每条电路生成多个候选再挑选。把挑选的开销算进去，这种自适应方法在 230 条任务上全部更慢。[各电路族的耗时和峰值内存](results/formal/preprocess.png)

## 2. 拿到一条新电路，怎样挑模拟器？

同一个振幅可以用张量网络、完整状态向量或图求值来算。实验每次留出一类电路，用其他类别的数据比较两种策略。一种为所有任务固定一个模拟器，另一种根据比特数、门数、深度等信息逐条选择。

**用原电路特征逐条选择，有 690/720 次运行完成并通过核对，固定选择为 660/720 次。** 在双方均通过核对的 220 条任务上，逐条选择的中位加速比为 28.0 倍。再提取消元后的结构特征，同样的 720 次运行中有 660 次通过核对。与只用原电路特征直接比较，新增特征在 220 条可比任务中的 216 条上增加了总耗时。[选择器实测结果](results/formal/selector.png)

## 3. 同一条电路反复改 T 门，哪些工作可以只做一次？

固定电路骨架、输入和目标输出，只把指定位置的门在 T 与 T† 之间切换。一次准备好可复用的图，再逐次更新门的取值，与每次重建图使用相同的求值后端。

**每批 128 次查询时，共享图在全部 8 个骨架上都更快。** 与逐次重建相比，四个图态骨架的中位加速比为 **7.54 倍**，四个 IQP 骨架为 **1.80 倍**。图态骨架只有四个可变位置，因此 128 次查询包含 16 种不同填法，每次都重新求振幅。[各骨架的批量耗时](results/formal/batch_by_task.png)

## 数据与复现

正式集包含六类电路、240 条任务，每种方法重复三次。230 条任务有参考振幅，其余 10 条 Grover 任务标记为未核验。上文的加速比先对每条任务的三次耗时取中位数，再计算基线与新方法的耗时比，最后对通过核对的配对任务取中位数。实验使用一台 CPU、单个计算线程，每项任务限时 60 秒，内存预算为 2 GiB。[正式报告](results/formal/RESULTS.md) · [逐例数据](results/formal/) · [核验记录](results/verification.json)

使用 Python 3.12，以下命令会运行四条小任务，覆盖全部三个实验。

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
python -m pip install --no-build-isolation --no-deps -e .
pfsparse-bench all --config configs/smoke.json --output results/my-smoke
```

分别运行三个实验时，将 `all` 换成 `preprocess`、`select` 或 `batch`。复跑正式集时使用 `configs/formal.json`，并指定新的输出目录。[实验配置](configs/) · [自定义批量查询示例](examples/custom_batch.json) · [源码来源](PROVENANCE.json)
